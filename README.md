# Brazilian E-Commerce Analytics Using Python

## Overview

This project analyzes a multi-table Brazilian e-commerce dataset (Olist) using Python, Pandas, Matplotlib, and Seaborn.

The objective was to build an end-to-end analytics workflow by integrating multiple datasets, performing data cleaning, relational joins, KPI analysis, and business visualizations.

## Key Activities

* Multi-table data integration
* Data cleaning and preprocessing
* Relational joins using Pandas merge
* KPI analysis
* Monthly revenue trend analysis
* Geographic revenue analysis
* Order status analysis
* Delivery performance analysis
* Business visualization

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* VS Code

## Key KPIs

* Total Revenue
* Total Freight Cost
* Average Product Price
* Total Orders
* Total Customers

## Visualizations

* Monthly Revenue Trend
* Revenue by State
* Order Status Distribution
* Delivery Delay Distribution

## Business Insights

* Identified revenue trends across time
* Analyzed regional sales performance
* Evaluated order fulfillment efficiency
* Measured delivery performance and delays
* Explored customer and order behavior
